MAIN FEATURES EXPLAINED
================================================================================

1. CODE UPLOAD & ANALYSIS
   - Accepts .sol files or pasted code
   - Validates syntax and checks for suspicious patterns
   - Uses Claude API for security analysis (DOESN'T WORK - no backend)

2. VERSION MANAGEMENT (V1, V2, etc.)
   - Stores contract versions in localStorage
   - Tracks parent-child version relationships
   - Associates fix submissions with versions
   - v1 = original, v2 = after fixes, etc.

3. FIX VERIFICATION
   - Users submit improved contract code
   - System analyzes against original issues (BROKEN)
   - Returns verification results and new issues found
   - Creates new version (v2) with results

4. ANALYTICS DASHBOARD
   - Metrics: total audits, avg score, issues found/fixed
   - Trends: historical score and issue patterns
   - Insights: AI-generated recommendations
   - Comparisons: multi-contract analysis

5. REPORT GENERATION
   - PDF: Professional formatted reports
   - JSON: Structured data export
   - HTML: Interactive web reports
